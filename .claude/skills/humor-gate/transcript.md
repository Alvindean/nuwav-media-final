## Why this video works (structure teardown)

1. **Hook = contrarian permission** (0–3s): "Just because X is funny like this doesn't mean you should." Instantly validates the viewer who *isn't* funny on camera.
2. **Name the pain precisely** (0:15): "funny with friends, not funny on video." Hyper-specific, so it feels personal.
3. **Contrast pair** (0:32–0:49): two famous, opposite comedians. The swap thought-experiment ("imagine if Marcello tried to be Nate") makes the concept obvious in one sentence: *one looks boring, the other looks like he's doing too much.*
4. **Proof clip**: a 4-second Bargatze bit shows deadpan instead of describing it.
5. **Open loop**: "There's still four others." Unresolved set = comments.
6. **Keyword CTA**: "Comment QUIZ" — drives comments (315) and saves (1.5K) → algorithm signal + DM funnel into a quiz.
7. **Set design does half the teaching**: the animal wall is on screen the whole time, so the framework is visible even with the sound off.
